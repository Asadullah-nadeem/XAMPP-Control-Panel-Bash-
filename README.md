 # XAMPP Control Panel (Bash)

## Overview
This is an interactive Bash script designed to simplify the management of XAMPP on Linux systems. With this script, users can:
- Start XAMPP services.
- Stop XAMPP services.
- Restart XAMPP services.
- Launch the XAMPP GUI.
- Exit the script with a confirmation prompt.

## Features
- User-friendly terminal menu for managing XAMPP.
- Beginner-friendly and easy to use.
- Efficient control of XAMPP services from a single script.
- Exit confirmation to prevent accidental closures.

## Getting Started

### Prerequisites
- XAMPP installed on your Linux system.
- Basic knowledge of terminal commands.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Asadullah-nadeem/xampp-control-panel-bash.git
   ```
2. Navigate to the project directory:
   ```bash
   cd xampp-control-panel-bash
   ```
3. Make the script executable:
   ```bash
   chmod +x manage_xampp.sh
   ```

### Usage
Run the script with:
```bash
./manage_xampp.sh
```

Follow the on-screen menu to manage XAMPP services.

### Menu Options
- `0` Start GUI XAMPP: Launches the XAMPP graphical interface.
- `1` Start XAMPP services: Starts the Apache and MySQL services.
- `2` Stop XAMPP services: Stops the Apache and MySQL services.
- `3` Restart XAMPP services: Restarts the Apache and MySQL services.
- `4` Exit the script: Closes the script after a confirmation.
